# Mappetizers
Useful little scripts for doing things in our collections or with GIS that don't merit their own repository

# Contents

* `airtable-file-downloader/`: Python script to batch download all of the file attachments from an exported Airtable CSV
* `allmaps-id-to-dc-manifest/`: Python notebook with syntax for combining Allmaps API with Digital Collections API
* `digital-collections-scraper/`: Python script to pull metadata out from LMEC Digital Collections repository
* `iiif-recursive-tiler/`: Bash script to recursively create IIIF pyramids
* `remap-boundary-to-plates/`: Contains two Python scripts used to re-map the Atlascope v1 metadata schema to the Atlascope v2 metadata schema
* `liiive-to-allmaps`: Warp Liiive annotations into GeoJSON using Allmaps CLI/API
* `notebooks-for-hugo-to-argo/`: Some python notebooks for translating Hugo shortcodes
* `pull-liiive-annotation-crops/`: Quick script for clipping IIIF images from Liiive annotations
* `get-long-maps.py`: Find maps with the most severe aspect ratio in LMEC collections
